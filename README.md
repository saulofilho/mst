## 🚩 Sobre o Projeto

O **MST (Movimento dos Trabalhadores Rurais Sem Terra)** é o maior produtor de arroz orgânico certificado da América Latina (reconhecido pela FAO/ONU e pelo IRGA há mais de dez safras consecutivas) e organiza centenas de cooperativas, agroindústrias comunitárias e escolas do campo em todo o Brasil.

A aplicação **Terra & Alimento** foi desenvolvida com dados **100% reais e auditados** para:
1. **Localizar Feiras e Lojas Físicas**: Encontrar onde comprar comida saudável e produtos da Reforma Agrária Popular perto de casa.
2. **Promover a Soberania Alimentar**: Difundir receitas nutritivas e tradicionais com ingredientes agroecológicos.
3. **Divulgar a História e os Fatos Positivos**: Apresentar os números reais e auditados da produção camponesa, reflorestamento e solidariedade ativa.
4. **Fomentar o Movimento e o Consumo Consciente**: Conectar consumidores e disponibilizar uma calculadora interativa de impacto social e ambiental.
5. **Apoiar a Segurança dos Assentados**: Canal ético e seguro de denúncias contra grileiros, pistolagem armada e pulverização criminosa de agrotóxicos, integrado aos órgãos oficiais de Direitos Humanos.

## 🚀 Como Executar Localmente

### Pré-requisitos
* **Node.js** (versão 18, 20 ou superior)
* **npm** ou **pnpm** / **yarn**

### Passo a passo
1. Clone o repositório:
```bash
git clone https://github.com/<seu-usuario>/<seu-repositorio>.git
cd <seu-repositorio>
```

2. Instale as dependências:
```bash
npm install
```

3. Inicie o servidor de desenvolvimento:
```bash
npm run dev
```

4. Abra no seu navegador:
```
http://localhost:3000
```

5. Para gerar o build de produção:
```bash
npm run build
```

## 🌐 Publicação no GitHub Pages

O projeto já está 100% configurado para rodar no **GitHub Pages**!

### Método 1: Automático via GitHub Actions (Recomendado)
O repositório já inclui o arquivo de workflow pronto em `.github/workflows/deploy.yml`.

1. Envie o código para o GitHub:
```bash
git add .
git commit -m "feat: app mst com dados reais e github pages"
git push origin main
```
2. No seu repositório no GitHub, vá em **Settings** > **Pages**.
3. Na seção **Build and deployment**, em **Source**, selecione **GitHub Actions**.
4. O GitHub executará o build automaticamente e disponibilizará o link público (ex: `https://<seu-usuario>.github.io/<seu-repositorio>/`).

---

### Método 2: Manual via pacote `gh-pages`
Também está configurado o script `npm run deploy` via pacote `gh-pages`:

1. Execute no terminal:
```bash
npm run deploy
```
2. Este comando executará `npm run build` e publicará a pasta `dist` na branch `gh-pages`.
3. No GitHub, em **Settings** > **Pages**, selecione a branch `gh-pages` e a pasta `/ (root)`.

## 📱 Funcionalidades da Aplicação

* 🗺️ **Mapa Interativo**:
  - Filtros por estado e tipo de ponto (Armazém, Feira, Cesta, Cooperativa).
  - Cálculo de distância via GPS (API Geolocation do navegador) pelo algoritmo de Haversine.
  - Traçado de rota direto no Google Maps.
  - Link direto para o WhatsApp dos Armazéns.
  - Salvamento de locais favoritos no `localStorage`.

* 🍲 **Receitas da Terra**:
  - Pratos elaborados com os produtos colhidos pelas cooperativas.
  - Checklist interativo de despensa.
  - Dicas agroecológicas de aproveitamento integral.
  - Botão "Localizar Ingredientes" que conecta a receita diretamente às feiras mais próximas.

* 📖 **História & Linha do Tempo**:
  - Quatro décadas de marcos históricos (1984 a 2026).
  - Artigos 184 a 189 da Constituição Federal de 1988.
  - Conquistas com fontes auditadas.

* 💡 **Calculadora Popular de Impacto Saudável**:
  - Simula em tempo real a redução de agrotóxicos ingeridos, CO₂ evitado e renda revertida para a agricultura familiar com base no consumo mensal da família.

* 🛡️ **Canal de Denúncias e Apoio à Segurança**:
  - Opção 100% anônima para proteger a identidade do relator.
  - Geração de protocolo seguro (ex: `DEN-MST-2026-XXXX`).
  - Consulta de andamento de protocolos.
  - Guia emergencial de segurança no campo e telefones oficiais.

* 📬 **Boletim Popular da Terra (Newsletter)**:
  - Assinatura direta no rodapé para receber o calendário de feiras, novas safras de arroz orgânico, receitas sazonais e informes das conquistas camponesas.
  - Validação de e-mail e persistência local para controle de inscrição.
